# 地名检索池

地理搜索只在数据刷新阶段运行，浏览器运行时只读取已经写入的坐标和缓存。

## 默认池

| 顺序 | Provider | 认证 | 适用性 | 当前策略 |
| --- | --- | --- | --- | --- |
| 1 | Photon | 无 | 中国地名有一定覆盖，当前网络环境可达 | 每个查询都检索，6 秒超时 |
| 2 | Nominatim | 无 | OSM 地名覆盖较好，但有公共服务限流 | 同一查询并行逻辑上的第二候选，8 秒超时 |
| 3 | ArcGIS World Geocoder | 无 | 全球兜底，国内链路可能超时 | 同一查询最后候选，4 秒超时 |

同一查询会收集所有当前可用 provider 的可信候选：用地点名称匹配质量和坐标质量选择主坐标，再合并同一地点范围内的 `country`、`province`、`city`、`district`、`locality`、道路和门牌字段。每个 provider 连续失败两次后，本次刷新跳过该 provider，避免一个不可达服务拖慢全部地名。结果必须同时满足地点名称和目标城市归属校验；没有可信结果时保留城市级 fallback。

写入的数据同时保留 `destinationLocality` 和 `destinationAddress`。前者用于地图的镇/街道精度标签，后者用于展示完整的格式化地址和可用的行政层级。景点名中的“景区”等后缀不会被误判为行政区。

## 国内服务边界

高德、腾讯位置服务、百度地图、天地图的地理编码服务通常需要申请 key，不能作为当前“零门槛”默认 provider。后续若配置合法 key，应增加独立 adapter 和配额限制，不要把 key 写入前端或提交到仓库。

## 刷新方式

```powershell
python scripts/rebuild_geo_data.py --network
```

成功结果写入 `scripts/geo-geocode-cache.json`，之后可以不联网重建地图索引。缓存只保存公开搜索结果和坐标，不保存用户信息或访问凭据。
